# cat-eat-what · 猫猫今天吃什么

> 2-4 人实时联机的微信小游戏：每只猫选一道美食，通过「食材跑酷」和「料理大乱斗」两关决出胜负，赢家选的美食就是今晚的答案。

## 当前状态

**设计阶段，暂不写业务代码。**  
完整的产品、技术、美术、部署、合规文档在 [`docs/`](./docs/README.md)。

## 已确定的方向

- 平台：微信小游戏（公开上架）
- 客户端：Cocos Creator 3.8 LTS + TypeScript
- 服务端：Node.js 20 LTS + TypeScript + WebSocket
- 人数：2-4 人，微信分享卡片拉人
- 选餐：公开，所有玩家可见
- 第一关：食材跑酷，绿光跳起来吃，红光蹲下躲
- 第二关：俯视角料理大乱斗，摇杆 + 攻击 + 闪避
- 分数：第二关最低 0 分
- 结算：总分最高者的美食获胜
