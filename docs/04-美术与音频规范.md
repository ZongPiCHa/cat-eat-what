# 04 · 美术与音频规范

> 风格关键词：温馨、明亮、可爱、贴纸绘本、圆润、软阴影、低饱和背景 + 高饱和角色  
> 目标：让 2-4 只猫一眼可区分，让「绿光/红光」在 1 秒内可读，让输家也觉得可爱。

---

## 1. 视觉风格

### 1.1 关键词

- 手绘贴纸感：粗描边、圆角、轻微不规则。
- 明亮奶油色背景，食物和猫使用高饱和暖色。
- 柔软阴影，不用纯黑硬阴影。
- 角色比例：大头、小身体、短腿、圆眼睛。
- 动作夸张但可爱，不暴力。
- 食物是「贴纸/图标」质感，不是写实摄影。

### 1.2 不要的风格

- 写实、暗黑、赛博、像素风。
- 血腥、尖锐武器、恐怖表情。
- 过度渐变、玻璃拟态、复杂 3D。
- 大量高速闪烁（审核和舒适度都不友好）。
- 与知名 IP 相似的角色/食物包装。

### 1.3 参考构图

- 首页：一只猫从奶油色背景探出头，周围漂浮食物贴纸。
- 大厅：野餐桌/厨房台面，四个猫座位围成一圈。
- 第一关：美食街横向卷轴，三层视差。
- 第二关：俯视野餐垫擂台，四个角有餐具装饰。
- 结算：获胜猫举着美食，彩色纸屑。

## 2. 色彩规范

### 2.1 主色板

| 名称 | Hex | 用途 |
|---|---|---|
| 奶油白 | `#FFF7E8` | 主背景 |
| 黄油 | `#FFE3A3` | 次级背景、卡片 |
| 杏色 | `#FFC46B` | 高亮、按钮渐变 |
| 橘色 | `#FF9F43` | 主按钮、强调 |
| 珊瑚 | `#FF6F61` | 次强调、错误提示 |
| 薄荷 | `#8FD9B6` | 正确、安全 |
| 天空 | `#9ED8E8` | 辅助、冷色点缀 |
| 深棕 | `#4A2E17` | 主文字、描边 |
| 可可 | `#7A4A26` | 次级文字 |
| 白色 | `#FFFFFF` | 卡片、高光 |
| 阴影 | `rgba(74,46,23,0.12)` | 软阴影 |

### 2.2 功能色

| 状态 | 颜色 | 辅助 |
|---|---|---|
| 正确/绿色食材 | `#5BC97A` | ✓ 图标 + 轻快音效 |
| 错误/红色食材 | `#FF5A5A` | ✗ 图标 + 低沉音效 |
| 0 分保护 | `#FFD54F` | 小盾牌图标 |
| 受击提示 | `#FFB74D` | 屏幕边缘暖色闪 |
| 网络警告 | `#FFB74D` | 文字 + 图标 |
| 禁用 | `#C9B8A6` | 降低透明度 |

### 2.3 配色原则

- 背景永远比角色低饱和，保证角色跳出来。
- 绿色/红色必须同时有图标和形状差异，不能只靠颜色。
- 文字对比度满足可读性：深棕文字在奶油底上。
- 同屏不超过 3 个高饱和主色块，避免花。

## 3. 角色设计

### 3.1 四只猫

| 猫 | 主色 | 花纹 | 配饰 | 性格 |
|---|---|---|---|---|
| 橘猫 | `#F6A94A` | 深橘条纹 `#D9822B` | 红围巾 | 贪吃、热情 |
| 奶牛猫 | `#F7F3EA` | 黑色斑块 `#3E3A39` | 蓝领结 | 活泼、爱闹 |
| 黑猫 | `#4A4A55` | 无 | 黄铃铛 | 冷静、酷 |
| 三花猫 | `#F7E7D3` | 橘/黑斑块 | 粉蝴蝶结 | 温柔、机灵 |

### 3.2 可区分性

- 剪影：围巾、领结、铃铛、蝴蝶结，即使黑白也能区分。
- 颜色 + 配饰 + 体型微差异（黑猫稍瘦、橘猫稍圆）。
- 四只猫的猫名固定显示在头顶，减少识别成本。
- 色盲友好：不只靠毛色，配饰形状不同。

### 3.3 比例与尺寸

- 设计分辨率 750×1334。
- 第一关：猫站立高度约 180px，头部占比 55%。
- 第二关：俯视猫直径约 90px，武器约 70px。
- 结算：大头贴 240px。
- 描边 4-6px，圆角，软阴影偏移 4px。

### 3.4 表情

| 表情 | 用途 |
|---|---|
| 开心 | 大厅、吃到正确食材 |
| 期待 | 第一关准备 |
| 惊讶 | 红色食材出现 |
| 晕乎 | 吃到错误食材、眩晕 |
| 得意 | 第二关命中 |
| 委屈 | 被击中、0 分 |
| 胜利 | 结算 |

### 3.5 动画清单

| 动画 | 帧数/时长 | 循环 | 说明 |
|---|---|---|---|
| idle | 4 帧 / 1.2s | 是 | 呼吸、眨眼 |
| run | 6 帧 / 0.6s | 是 | 第一关奔跑 |
| jump | 4 帧 / 0.55s | 否 | 起跳、腾空、落下 |
| duck | 3 帧 / 0.6s | 否 | 缩成一团 |
| eat | 4 帧 / 0.4s | 否 | 张嘴、咀嚼 |
| dizzy | 4 帧 / 0.8s | 是 | 蚊香眼、转圈 |
| hit | 3 帧 / 0.35s | 否 | 后仰、星星 |
| attack | 5 帧 / 0.4s | 否 | 挥武器 |
| dodge | 3 帧 / 0.22s | 否 | 残影冲刺 |
| win | 6 帧 / 1.5s | 是 | 举食物、跳 |
| lose | 4 帧 / 1.2s | 是 | 趴下、耳朵垂 |
| cheer | 4 帧 / 1s | 是 | 大厅待机 |

- 动画帧率 12-24 FPS，导出 Sprite Sheet。
- 关键动作要有预备/跟随，避免僵硬。
- 受击/眩晕不超过 0.5 秒的剧烈闪烁。

## 4. 美食与食材

### 4.1 六道美食

每道菜需要：

- 菜单图标 128×128。
- 大厅卡片插画 300×220。
- 第二关武器 128×128。
- 结算大头贴 256×256。
- 命中特效元素。

| 美食 | 主色 | 武器 | 特效 |
|---|---|---|---|
| 火锅 | 红 `#E5533D` | 大汤勺/小锅 | 红油、辣椒、花椒 |
| 麻辣烫 | 橙红 `#F26B3A` | 漏勺 | 汤汁、丸子、海带 |
| 盖饭 | 米白/棕 `#E8B26A` | 饭勺 | 米粒、酱汁 |
| 炸鸡 | 金 `#F2B33D` | 鸡腿锤 | 脆皮、油星 |
| 汉堡 | 棕/绿 `#C98A4B` | 汉堡盾/砸 | 生菜、芝麻、芝士 |
| 披萨 | 红/黄 `#E86A3A` | 披萨回旋 | 芝士拉丝、番茄酱 |

### 4.2 食材图标

- 每个食材 96×96 贴纸图标，统一描边和光源。
- 图标 + 名称一起显示，避免「辣椒/花椒」混淆。
- 食材池约 30-40 个，首版可先用 emoji 占位，后期替换。
- 食材颜色不固定为红/绿，红绿光晕是外圈效果，不能改变食材本身颜色。

### 4.3 红绿光晕

- 绿色：外圈 `#5BC97A` 发光 + ✓ 角标 + 轻微呼吸。
- 红色：外圈 `#FF5A5A` 发光 + ✗ 角标 + 轻微抖动。
- 光晕不能遮挡食材图标 30% 以上。
- 发光用 Sprite + 叠加，不用实时 Shader（性能）。
- 红绿光晕同时出现在食材卡片和飞行拖尾上。

### 4.4 干扰食材

- 米饭、面条、饺子、寿司、蛋糕、西兰花、草莓、牛奶、玉米、包子、沙拉、冰淇淋。
- 风格与正确食材一致，不能一眼看出是「假食材」。

## 5. 场景

### 5.1 首页

- 奶油色背景 + 漂浮食物贴纸 + 一只探头猫。
- 标题手写感，但使用可商用字体或系统字体加粗。
- 底部留出版本号/隐私入口。
- 安全区适配：刘海屏不遮挡标题。

### 5.2 大厅

- 野餐桌/厨房台面俯视或斜俯视。
- 四个座位围成一圈，空位显示虚线猫爪。
- 中间是 6 道菜的卡片网格。
- 房主有皇冠/小旗标识。
- 选餐公开：每个座位旁显示所选美食图标。
- 背景可加入窗户、绿植、餐具，保持简洁。

### 5.3 第一关

三层视差：

1. 远景：天空、云、远处美食街招牌（低饱和）。
2. 中景：摊位、灯笼、食物招牌（中饱和）。
3. 近景：地面、桌布、跑动尘埃（高饱和）。

- 地面高度约画面 72%。
- 猫在左侧 28%，食材从右侧进入。
- 背景元素不遮挡食材和按钮。
- 不使用高频闪烁的霓虹灯。

### 5.4 第二关

- 俯视野餐垫擂台，圆角矩形。
- 四周：盘子、叉子、杯子、餐巾（装饰，不参与碰撞）。
- 中央可有淡淡猫爪印/格纹。
- 角色和武器在背景上高对比。
- 受击特效不使用红色大面积闪烁。

### 5.5 结算

- 奶油色背景 + 彩纸 + 获胜猫大头贴。
- 获胜美食大图标。
- 排名卡片圆角、软阴影。
- 分享卡片：竖版 5:4 或 1:1，包含猫、美食、文案、二维码/小程序码（按平台能力）。

## 6. UI 规范

### 6.1 基础组件

| 组件 | 规格 |
|---|---|
| 主按钮 | 高 96px，圆角 48px，橘色渐变，白字，软阴影 |
| 次按钮 | 高 88px，圆角 44px，奶油底 + 棕描边 |
| 卡片 | 圆角 32px，白/奶油底，阴影 8px |
| 弹窗 | 圆角 40px，宽 620px，底部按钮 |
| 标签 | 圆角 999px，小字号 |
| 头像框 | 圆形/圆角，房主皇冠角标 |
| 摇杆 | 底盘 200px，摇杆头 96px |
| 动作按钮 | 直径 110px，冷却环 |

### 6.2 字体

- 中文：系统字体（PingFang SC / 思源黑体）优先，避免商用字体授权风险。
- 数字：可使用圆体/粗体，但需确认商用许可。
- 标题：加粗、字间距略大。
- 正文：不小于 24px（设计分辨率），保证手机可读。
- 不使用未授权的手写字体。

### 6.3 触控

- 最小触控热区 88×88px。
- 按钮之间留至少 24px 间距。
- 第一关「蹲/跳」左右分开，避免误触。
- 第二关摇杆和按钮在底部安全区内。
- 刘海屏/底部横条适配。

### 6.4 HUD

- 分数数字使用大号粗体，变化时弹跳。
- 排名使用猫头像 + 分数，不堆文字。
- 倒计时最后 10 秒变橙，不闪红。
- 网络警告用顶部小条，不遮挡操作。

### 6.5 分享图

- 尺寸按微信分享卡片要求，建议 5:4。
- 内容：获胜猫 + 美食 + 「今晚吃火锅！」+ 游戏名。
- 不使用用户头像/昵称（首版没有）。
- 不出现「分享得奖励」等诱导文案。

## 7. 动效与特效

### 7.1 第一关

| 事件 | 特效 | 时长 |
|---|---|---|
| 绿色食材出现 | 绿色光晕 + ✓ + 轻微呼吸 | 持续到判定 |
| 红色食材出现 | 红色光晕 + ✗ + 轻微抖动 | 持续到判定 |
| 吃掉绿色 | 星星、+1 飘字、猫咀嚼 | 0.5s |
| 未命中绿色 | 小灰尘、猫疑惑 | 0.3s |
| 吃到红色 | 辣椒爆开、蚊香眼、屏幕轻晃 | 1.2s |
| 躲开红色 | 薄荷色闪一下、猫得意 | 0.3s |
| 跳过食材 | 食材淡出、灰色「跳过」 | 0.3s |

### 7.2 第二关

| 事件 | 特效 | 时长 |
|---|---|---|
| 攻击挥击 | 武器拖尾、食材碎屑 | 0.3s |
| 命中 | 星星、酱汁、-1 飘字、击退 | 0.4s |
| 受击 | 猫后仰、晕眩星星 | 0.35s |
| 闪避 | 残影、薄荷色线条 | 0.22s |
| 0 分保护 | 小盾牌、金色光圈 | 0.3s |
| 最后 15 秒 | 屏幕边缘暖色脉冲 | 循环 |
| 胜利 | 彩纸、举食物、猫叫 | 1.5s |

### 7.3 原则

- 特效不遮挡判定区域。
- 同屏粒子上限 120。
- 不使用全屏白闪/红闪。
- 低端机可关闭部分粒子（设置项：精简特效）。

## 8. 音频规范

### 8.1 BGM

| 场景 | 风格 | 时长 | 循环 |
|---|---|---|---|
| 首页/大厅 | 尤克里里 + 木琴，轻松温暖 | 60-90s | 是 |
| 第一关 | 轻快鼓点 + 木琴，节奏 110-120 BPM | 60s | 是 |
| 第二关 | 俏皮打击乐 + 铜管点缀，120-130 BPM | 75s | 是 |
| 结算 | 小号/铃声胜利旋律 | 5-8s | 否 |

- 使用原创或可商用免版税音乐，保留授权记录。
- BGM 音量 -18 LUFS 左右，不压过音效。
- 场景切换淡入淡出 0.3s。
- 切后台暂停，回前台恢复（可在设置关闭）。

### 8.2 音效

| 音效 | 时长 | 说明 |
|---|---|---|
| 按钮点击 | 80ms | 软木「啵」 |
| 加入房间 | 200ms | 猫叫 + 铃铛 |
| 倒计时 | 100ms × 3 | 木鱼/铃声 |
| 跳跃 | 150ms | 弹簧「boing」 |
| 蹲下 | 120ms | 布料摩擦 |
| 吃掉正确 | 200ms | 咀嚼 + 清脆铃 |
| 未命中 | 150ms | 轻轻「嗯？」 |
| 吃到错误 | 300ms | 辣椒「噗」+ 晕眩 |
| 躲开 | 150ms | 风声 |
| 攻击挥击 | 120ms | 挥动 |
| 命中 | 200ms | 软软的「bonk」+ 星星 |
| 被击中 | 200ms | 猫「喵呜」 |
| 闪避 | 150ms | 呼呼 |
| 0 分保护 | 250ms | 小盾牌「叮」 |
| 胜利 | 1.5s | 欢呼 + 猫叫 |
| 失败 | 1s | 委屈猫叫，不悲伤过度 |
| 网络错误 | 200ms | 软提示音 |

- SFX 单声道，44.1kHz，MP3/OGG。
- 同一音效最多同时 3 个，避免叠音。
- 音效音量 -12 LUFS 左右。
- 提供音乐/音效独立开关。

### 8.3 语音

- 首版不做真人语音/自由语音。
- 可用短促猫叫作为反馈，需原创或授权。
- 不使用 copyrighted 音效包。

## 10. 可访问性与舒适度

- 红绿之外必须有 ✓/✗ 和不同音效。
- 按钮足够大，支持左手/右手操作。
- 设置中提供「精简特效」「关闭震动」。
- 不出现快速闪烁（每秒 > 3 次）。
- 文字对比度足够，不用浅色字叠浅色背景。
- 眩晕/受击表现不遮挡操作区。
- 音效可单独关闭，不强制听 BGM。
