# 09 · 交互流程与页面状态

> 本文把 GDD 的页面流程拆到「按钮、状态、异常、文案」级别，供客户端和 UI 直接实现。  
> 设计原则：少层级、少弹窗、任何异常都能回到首页或重试。

---

## 1. 全局导航

```
Boot
  └─ Home
       ├─ Create Room → Lobby
       ├─ Join by Code → Lobby
       ├─ Practice → Level1 → Transition → Level2 → Result
       └─ Settings
Lobby
  ├─ Start → Level1 → Transition → Level2 → Result
  └─ Leave → Home
Result
  ├─ Rematch → Lobby
  ├─ Share
  └─ Home
```

- 页面切换使用淡入淡出 0.2 秒，避免硬切。
- 游戏内不允许系统返回键直接退出；先弹确认。
- 任何网络错误弹窗都提供「重试」和「回首页」。
- 首页始终是安全兜底页。

---

## 2. 启动与登录

### 2.1 启动流程

1. 显示 Logo/猫爪加载动画。
2. 检查本地 token。
3. 调用 `wx.login` → `/api/login`。
4. 拉取 `/api/config`。
5. 检查版本。
6. 进入首页。

### 2.2 状态

| 状态 | 表现 | 处理 |
|---|---|---|
| 加载中 | 猫爪转圈 + 进度条 | 正常 |
| 登录失败 | 弹窗「猫猫没连上，再试一次」 | 重试/回首页 |
| 配置失败 | 使用内置兜底配置 | 静默 |
| 版本过低 | 弹窗「请更新到最新版本」 | 引导重启/更新 |
| 无网络 | 弹窗「网络不太好」 | 重试 |
| 隐私未同意 | 展示隐私摘要 | 同意后继续 |

### 2.3 首次启动

- 展示一页隐私政策摘要，不阻塞阅读。
- 按钮：「同意并继续」/「查看完整隐私政策」。
- 不同意：不能进入联机，但可查看隐私政策/退出。
- 不请求头像、昵称、位置、通讯录。

## 3. 首页

### 3.1 布局

- 顶部：Logo/标题「猫猫今天吃什么」。
- 中部：探头猫 + 漂浮食物贴纸。
- 按钮：
  - 创建房间（主按钮）
  - 输入房间号（次按钮）
  - 单人练习（次按钮）
- 底部：设置、隐私政策、用户协议、版本号。

### 3.2 交互

| 操作 | 行为 |
|---|---|
| 创建房间 | 连接 WS → create_room → 进入大厅 |
| 输入房间号 | 弹出 6 位输入框 → join_room |
| 单人练习 | 创建本地/服务端练习局 → 第一关 |
| 设置 | 打开设置页/弹窗 |
| 隐私政策 | 打开网页/内置页 |
| 版本号 | 连点 5 次可显示调试信息（仅开发） |

### 3.3 房间号输入

- 6 位，自动转大写。
- 输入框只允许字母/数字。
- 不足 6 位时「加入」禁用。
- 错误提示：
  - 房间不存在：「没有找到这个房间」
  - 房间满：「房间满啦」
  - 已开始：「这局已经开吃啦，等下一局」
- 加入成功后进入大厅。

### 3.4 分享进入

- 冷启动/热启动读取 `roomId`。
- 未登录：先登录，再自动加入。
- 已在其他房间：提示「要先离开当前房间吗？」。
- 加入失败：提示原因 + 「创建一个新房间」。

---

## 4. 大厅

### 4.1 布局

- 顶部：房间号 + 复制 + 邀请。
- 中部：4 个座位（头像、猫名、房主标识、所选美食）。
- 下部：6 道美食选择网格。
- 底部：开始按钮（房主）/等待提示（非房主）/离开。

### 4.2 座位状态

| 状态 | 表现 |
|---|---|
| 空位 | 虚线猫爪 + 「等待猫猫」 |
| 已加入未选餐 | 猫头像 + 「还没选」 |
| 已选餐 | 猫头像 + 美食图标 + 美食名 |
| 房主 | 皇冠/小旗角标 |
| 断线 | 灰色 + 「重连中」 |
| AI（仅练习） | 机器人角标 |

### 4.3 选餐

- 点击美食卡片 → 立即选中并广播。
- 已选中的卡片高亮 + 勾选。
- 可以反复更换，直到开始。
- 选餐公开：其他人实时看到。
- 两人可选同一道菜，不冲突。
- 选餐后按钮文案变为「换一道」。

### 4.4 开始按钮

| 条件 | 状态 | 文案 |
|---|---|---|
| 少于 2 人 | 禁用 | 再叫一只猫来 |
| 2-4 人，全部已选 | 可用 | 开始游戏 |
| 2-4 人，有人未选 | 可用 | 开始游戏（未选将随机） |
| 非房主 | 隐藏/禁用 | 等房主开饭… |
| 正在开始 | 加载 | 上菜中… |

- 点击开始后，若有未选玩家，弹确认：
  - 「XX 还没选，开始后会随机帮 TA 选，确定吗？」
  - 确认/取消。
- 开始后房间锁定，显示 3-2-1 倒计时。

### 4.5 邀请

- 点击「邀请好友」→ 微信分享面板。
- 分享标题/封面固定。
- 分享成功后本地 Toast「已发送邀请」。
- 不强制分享、不承诺奖励。

### 4.6 离开

- 点击离开 → 确认弹窗。
- 房主离开 → 提示「房主会转给下一位猫猫」。
- 游戏中离开 → 确认「离开后由 AI 接管，确定吗？」。
- 确认后回首页。

## 5. 第一关

### 5.1 进入

- 显示 3-2-1 倒计时。
- 显示目标美食 + 操作提示：
  - 「你的目标：火锅」
  - 「绿色 ✓ 跳 / 红色 ✗ 蹲」
- 第一次玩显示完整教学；之后可跳过。

### 5.2 游戏中

- 顶部：自己分数、倒计时、其他玩家进度条。
- 中部：猫、食材、红绿光晕。
- 底部：蹲/跳按钮。
- 红色食材命中：屏幕轻晃 + 眩晕 + 「好辣！」。
- 绿色食材吃掉：+1 飘字 + 星星。
- 未命中：轻微提示，不打断。
- 暂停：切后台自动暂停表现，回前台恢复；不提供手动暂停（多人）。

### 5.3 结束

- 倒计时结束/24 个食材处理完。
- 显示「第一关完成！」+ 分数 + 排名。
- 3 秒后进入过渡页。

### 5.4 断线

- 顶部显示「重连中」+ 旋转猫爪。
- 分数冻结。
- 重连成功：Toast「猫猫回来了！」+ 从当前时间继续。
- 重连失败：本关结束，使用最后分数。

---

## 6. 过渡页

### 6.1 内容

- 标题「第一关结果」。
- 四只猫的分数排名。
- 每只猫的目标美食高亮（选餐公开，但这里再次强调）。
- 3 秒倒计时「准备开打」。
- 可点击「跳过」？多人同步不建议跳过；固定 3 秒。

### 6.2 全员同菜

- 不进入过渡页，直接结算：
  - 标题「全票通过！」
  - 大字「今晚吃火锅」
  - 按钮「友谊赛」/「再来一局」

---

## 7. 第二关

### 7.1 进入

- 显示 3-2-1 倒计时。
- 显示自己的美食武器。
- 提示「摇杆移动，攻击/闪避」。

### 7.2 游戏中

- 顶部：四只猫头像 + 分数 + 排名 + 倒计时。
- 中部：固定擂台、四只猫。
- 底部：摇杆 + 攻击 + 闪避。
- 命中：-1 飘字、星星、击退。
- 被击中：屏幕边缘暖色、猫晕眩。
- 0 分保护：小盾牌 + 「0 分保护中」。
- 最后 15 秒：倒计时变橙 + 音乐加快。
- 网络警告：顶部小条，不遮挡操作。

### 7.3 结束

- 75 秒结束 → 结算。
- 平局 → 15 秒加时：
  - 顶部显示「加时！先命中者胜」。
  - 分数锁定。
  - 首次命中 → 立即结束。
  - 无命中 → 双拼。

### 7.4 断线

- 3 秒后 AI 接管，头像变灰 + 「AI 接管」。
- 重连成功：Toast「猫猫回来了！」+ 恢复控制。
- 30 秒未回：座位释放，AI 打到结束。

---

## 8. 结算

### 8.1 内容

- 获胜猫大头贴 + 皇冠。
- 大字「今晚吃火锅！」。
- 获胜美食大图标。
- 四行排名：猫名、分数、美食图标。
- 平局双拼：两道菜并排。
- 全员同菜：全票通过。
- 按钮：
  - 就吃这个（分享）
  - 再来一局（房主）
  - 回大厅
- 非房主点「再来一局」→ 发送「想再来一局」提示。

### 8.2 分享

- 点击「就吃这个」→ 微信分享面板。
- 分享图：获胜猫 + 美食 + 文案。
- 分享成功后不弹奖励。
- 可复制结果文案。

### 8.3 再来一局

- 房主点击 → 回到大厅。
- 保留玩家和美食选择，分数清零。
- 玩家可重新选餐。
- 非房主点击 → 房主收到 Toast「XX 想再来一局」。

## 9. 设置

### 9.1 项

- 音乐开关。
- 音效开关。
- 震动开关。
- 精简特效。
- 重看教学。
- 隐私政策。
- 用户协议。
- 版本号。
- 清除本地缓存（谨慎）。
- 反馈/客服入口（后续）。

### 9.2 行为

- 开关立即生效并持久化。
- 静音不影响游戏逻辑。
- 重看教学只在下一次第一关生效。

## 10. 网络与异常

### 10.1 全局网络状态

| 状态 | 表现 | 操作 |
|---|---|---|
| 连接中 | 顶部小条「连接中…」 | 自动 |
| 断线 | 弹窗/小条「猫猫掉线了」 | 自动重连 |
| 重连中 | 旋转猫爪 + 倒计时 | 可回首页 |
| 重连失败 | 弹窗「没连上」 | 重试/回首页 |
| 服务器维护 | 弹窗「猫猫们在休息」 | 回首页 |
| 版本不符 | 弹窗「请更新」 | 重启 |

### 10.2 异常场景

| 场景 | 处理 |
|---|---|
| 房间被销毁 | 提示 + 回首页 |
| 被房主移出（后续） | 提示 + 回首页 |
| 重复登录 | 旧设备提示「账号在别处登录」 |
| 时间不同步 | 重新校准；仍失败提示 |
| 资源加载失败 | 重试/降级/回首页 |
| 分享失败 | Toast「分享失败，再试一次」 |
| 剪贴板失败 | 手动展示房间号 |

### 10.3 错误文案

- 统一语气：猫猫、吃饭、网络。
- 不展示技术错误码给用户。
- 开发环境显示 code，生产环境隐藏。
- 所有错误弹窗最多两个按钮，避免选择困难。

## 11. 动效与转场

| 转场 | 效果 | 时长 |
|---|---|---|
| 首页 → 大厅 | 淡入 + 猫爪 | 0.25s |
| 大厅 → 第一关 | 圆形放大 + 倒计时 | 0.4s |
| 第一关 → 过渡 | 淡出 + 结果卡 | 0.3s |
| 过渡 → 第二关 | 擂台展开 | 0.4s |
| 第二关 → 结算 | 彩纸 + 大头贴 | 0.6s |
| 弹窗 | 缩放 + 淡入 | 0.2s |
| Toast | 上滑 + 淡出 | 2s |

- 动效可被「精简特效」降低。
- 不使用全屏闪烁。
- 转场期间不接受重复点击。

---

## 12. 可访问性

- 所有按钮有文字/图标，不只靠颜色。
- 红绿食材有 ✓/✗ 和音效。
- 触控热区 >= 88×88px。
- 文字对比度足够。
- 支持关闭震动/音效。
- 支持精简特效。
- 不强制横屏/竖屏切换。
- 安全区适配刘海和底部横条。
